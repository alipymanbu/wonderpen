## 它到底好在哪？

### 树状目录，管大纲像管文件夹

妙笔最核心的设计就是树状目录。写长篇小说、毕业论文、系列文章，目录层级可以无限嵌套，章节之间拖来拖去排序、调整从属关系，跟整理文件夹一样顺手。

想先搭好整体大纲再逐章填充内容？可以。想先一口气写完再切分章节？也行——右键就能把一篇长文按段落拆开，或者把多个章节合并成一个。

### 专注模式，真的能让人安静下来写字

全屏专注模式下，所有工具栏、目录、侧边栏全都消失，屏幕上只剩下你和文字。打字机模式把光标锁定在屏幕中央，视线不用一直追着文字往下跑。

这些功能单独拿出来说好像没什么，但真正打开来写的时候，你会发现那种沉下去的感觉来得特别快。

### 备份这件事，妙笔替你想到了

每15分钟自动全库备份一次，最近改动过的文档还额外支持快照——你可以随时翻出某个历史版本，和当前内容逐字对比差异。

写长篇的人都懂，最怕的不是写不出来，是写出来的东西丢了。妙笔在这块下了很多功夫。
